# マウス後足 microCT — VRLサンプル

出典: Kenney HM, Awad H (University of Rochester Medical Center). "Training Datasets: A High-Throughput Semi-Automated Bone Segmentation Workflow for Murine Hindpaw Micro-CT Datasets", Mendeley Data, Version 1 (2021). DOI: 10.17632/7sm9wznp6d.1
https://data.mendeley.com/datasets/7sm9wznp6d/1
元データ: 2か月齢メス C57BL/6 マウス（個体番号 889）の後足 microCT（"Example for 3D Visualization"）。
データライセンス: CC BY 4.0。https://creativecommons.org/licenses/by/4.0/
変更: 元の DICOM から片足分を切り出して面内を半分に縮小（346×306×408）。骨ラベルを解析領域（34件）に変換し、骨の名称を付与。本アプリで3D再構成。
注意: 元データは骨だけを残した 8-bit 値で、格納値は HU ではありません。
