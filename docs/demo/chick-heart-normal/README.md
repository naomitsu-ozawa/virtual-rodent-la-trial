# ニワトリ胚の心臓 microCT（正常・対照）— Virtual Rodent Lab 用データセット

ニワトリ胚の心臓の microCT を、Virtual Rodent Lab（VRL）で読み込める DICOM とプロジェクトファイルに変換したものです。ファロー四徴症モデル（TOF）のデータセットと対になる正常（対照、SHAM）個体です。

## 出典・ライセンス

- データセット: Rugonyi Lab（Oregon Health & Science University）"MicroCT scans -Control and TOF embryo hearts"、Dryad DOI: 10.5061/dryad.hdr7sqvg5
- ライセンス: **CC0 1.0**（パブリックドメイン）。出典表示は必須ではありませんが、上記の出典を明記してください。
- 原論文: Rykiel, G. et al. "Mechanobiology in congenital heart disease" — eLife 2020;9:e58138. DOI: 10.7554/eLife.58138
- 元ファイル: `CON_microCT.VOX`（Rigaku 形式）。スキャンフォルダ名には "quail" とありますが、データセットの公式ドキュメント（Readme）では chick embryo hearts と明記されているため、本データセットもニワトリ胚として扱います。

## 内容物

- `dicom_ct/` — DICOM CT 496枚（変換後ボリューム 496×266×366 ボクセル、間隔 0.020mm 等方）
- `chick_heart_con.vrlab` — VRLプロジェクトファイル（保存・検証済み）
- `sample.json` — VRLサンプルライブラリ登録用メタデータ
- `screenshot_children_3d.png` — VRLでの3D表示スクリーンショット（GPUボリューム）

## 変換の詳細（実測）

- 元データ形式: Vox1999a（412バイトASCIIヘッダ＋little-endian uint16）。寸法 512×512×512、間隔 0.020mm 等方。
- 格納値は HU ではなく元の値のまま保持しています。ヘッダには較正用の Field Scale/Offset が記録されていますが、ファイルによって値が異なり較正の適用可否が原資料で確認できないため、適用していません。
- 切り出し: 値3500以上の最大連結成分の外接範囲に余白12ボクセルを加えてクロップしました（元ボリュームの軸範囲 a0: 0–495、a1: 78–343、a2: 55–420）。ダウンサンプルはしていません。
- プロジェクトの初期設定: 「軟部組織」プリセットを有効化し、範囲を **3500〜14244**（このデータの最大値）に設定しています。これで心臓全体（9,938,285ボクセル）が拾えます。なお、この閾値では標本の底面で平らになった組織も一緒に含まれます（スキャン時の実データです）。

## 使い方・学習上の注意

- DICOMフォルダと .vrlab ファイルを VRL で一緒に読み込んでください。
- **このデータセットには構造名のラベルは付いていません。** 出典にもセグメンテーションは含まれていません。心房・心室・流出路などの構造を見分けて自分でセグメントやピンを作ることが、この教材での学習課題です。プロジェクトの閾値範囲はあくまで全体像をつかむための初期設定です。
- 対になるファロー四徴症モデル（TOF）と並べて観察すると、正常心との違いを比較できます。
