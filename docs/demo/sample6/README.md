# ジカウイルス EMD-8116 — VRLサンプル

出典: https://www.ebi.ac.uk/emdb/EMD-8116
Sirohi D, et al. The 3.8 Å resolution cryo-EM structure of Zika virus. Science (2016). DOI: 10.1126/science.aaf5316
元データ: cryo-EM密度マップ。複数粒子から平均再構成された構造であり、単一粒子の連続切片CTではありません。
データライセンス: CC0 1.0。https://www.ebi.ac.uk/pdbe/about/public-data-access-statement
https://creativecommons.org/publicdomain/zero/1.0/
変換: 768³から512³へ線形補間。密度値は1000倍してint16保存、RescaleSlope=0.001。
重要: VRL表示用に座標を100万倍に拡大。画面の1mmは実際の1nmに相当します。DICOM間隔0.156表示mmは実際0.156nmです。画面のmm・mm³を実寸と解釈しないでください。
サンプルの閾値3.5は公開元推奨の等値面。アプリの「骨」プリセットを密度面の表示枠として利用していますが、骨データではありません。
元の768³DICOMと利用者の編集済みプロジェクトは変更していません。
